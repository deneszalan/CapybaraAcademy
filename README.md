# Capybara Academy 🦫

Calm, step-by-step learning pages with a friendly capybara.

## Kapybaří akademie dějepisu / Capybara History Academy 📜

**Live page:** https://deneszalan.github.io/CapybaraAcademy/

History for Year 6 (6. třída), in Czech and English:

- **Prameny** – written, material and pictorial sources and where they are kept
- **Dějepis a čas** – past vs. history, cause → event → consequence, linear and cyclical time, periods of history
- **Vznik člověka** – creation theory, the theory of evolution, intelligent design
- **Test** – the same questions as the school test, with an answer checker and model answers

The whole page is one file, `index.html`, with no build step.
